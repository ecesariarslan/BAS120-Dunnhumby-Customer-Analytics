# BAS120 Dunnhumby Customer Analytics

Final project for BAS-120: Introduction to Analytics.

This project analyzes Dunnhumby customer transaction data and uses a Decision Tree classification model to identify customers who may become high-value customers.

## Project Highlights
- Customer transaction data analysis
- Feature engineering
- Decision Tree classification
- Model validation and testing
- Confusion matrix
- Feature importance analysis
- Business recommendations

## Final Model
The final Decision Tree model achieved approximately 85.5% test accuracy.
